How Discord Snowflake IDs Work

Discord uses 64-bit integers called Snowflake IDs for all entities (channels, users, messages, guilds). The first 42 bits represent the number of milliseconds elapsed since the custom Discord epoch (DISCORD_EPOCH = 1420070400000, corresponding to Jan 1, 2015 UTC).

Timestamp = (Snowflake_ID >> 22) + 1420070400000
